## Mandate

This repository defines the public visual specification of SOVRINT™.

The Visual Bible preserves the relationship between symbolic form, system architecture, graph topology, color, typography, hierarchy, observability, and public communication. Visual elements are treated as structural components of the same lattice expressed through a visual register.

## Core Scope

- canonical palette
- glyph registry
- icon and symbol rules
- topology grammar
- graph conventions
- manifold plates
- architecture diagrams
- observability visuals
- typography and spacing
- mobile-first layouts
- publication plates
- visual lineage

## Canonical Visual Principles

- deep navy, observability cyan, restrained gold, and white form the primary SOVRINT™ palette
- ivory paper may be used for poetry and literary artifacts
- text remains centered where designated
- icons may sit behind words without reducing readability
- mobile readability is mandatory
- no QR codes in canonical social visuals
- authorship and visual lineage remain visible

## Canonical Rules

1. Existing glyph meanings must not be reinterpreted without authorization.
2. Visual hierarchy must preserve conceptual hierarchy.
3. Public assets must be legible on mobile devices.
4. Source files, timestamps, and authorship must be preserved.
5. Protected diagrams or unreleased system topology must not be exported publicly.
6. Variants must retain a traceable relationship to the canonical source.
